# Система учета сбыта продукции сельскохозяйственного предприятия

Микросервисная архитектура на Python (FastAPI).

## Архитектура и сервисы
- **API Gateway** (`8000`) — единая точка входа, JWT-аутентификация, маршрутизация.
- **Product Service** (`8001`) — продукция, категории, складские остатки. Паттерны: *Factory Method*, *Proxy*.
- **Counterparty Service** (`8002`) — контрагенты, договоры. Паттерн: *Adapter* (заглушка для 1С).
- **Order Service** (`8003`) — заказы, отгрузки. Паттерны: *Facade*, *State*, *Observer*.
- **Finance Service** (`8004`) — платежи, задолженности.
- **Identity Service** (`8005`) — пользователи, роли, выдача JWT.

## Реализованная функциональность
- Микросервисы с собственными базами данных (SQLite).
- Межсервисное взаимодействие (Order Service запрашивает данные у Product и Counterparty).
- Устойчивость к отказам (возврат 503, если сервис недоступен).
- Ролевая модель доступа (JWT).
- 8 паттернов проектирования.
